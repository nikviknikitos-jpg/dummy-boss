# DummyBossMod (Fabric 1.20.1)

Проклятый Манекен-Тренер.

## Игра
- `dummyboss:dummy_spawner` — ПКМ по земле ставит манекен в Фазе 0 (Обучение).
- Бейте его 8 раз — он запомнит ваши удары (оружие, прыжки, стрейф, дальние атаки).
- Shift+ПКМ — пробуждение (если есть хотя бы 1 удар), начинается бой.
- Убейте — получите трофей и алмазы.

## Команда
- `/dummy` — выдать манекен.

## Сборка
JDK 17, Gradle 8.8.
